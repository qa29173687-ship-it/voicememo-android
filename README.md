# 錄音記事本 (Android)

中和安邦社宅現場用的錄音記事 App：錄音（背景/關螢幕可續錄）→ 存成「提醒／備忘／筆記」，附案號、棟別、樓層、定位地址，可一鍵上傳到 Google 雲端硬碟。

- 錄音：AAC m4a 44.1kHz 128kbps，暫停/繼續，通知列可停止
- 提醒：自動從標題/內容判斷時間（如「明天下午三點」），到時通知
- 備忘：置頂、勾選完成；筆記：長文/逐字稿、標籤
- 錄音同步存到「音樂/錄音記事本」，檔名 `yyyyMMdd_HHmmss_案號.m4a`

下載：見 Releases。需要 Android 8.0 以上。畫面預覽在 `previews/`。
